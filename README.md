# Alerta de nuevos turnos

Sistema de notificaciones via mail para alertar sobre nuevos turnos disponibles en el Portal de Pacientes del Hospital Italiano.

## Estado
➡️ Scrape del portal de turnos  
➡️ Extracción de los turnos próximos a un archivo .csv  
➡️ Notificación via mail  
➡️ Scheduling  

## Tecnologías
- Python 3.13.1
- Playwright 1.64.0
